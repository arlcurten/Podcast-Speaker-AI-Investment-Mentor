# Redacted Real Examples

This directory is reserved for small, manually selected and redacted real examples.

No redacted real examples are currently published here. Do not add complete transcript excerpts, full model outputs, or artifacts that could reconstruct an episode.

When adding a real example:

1. Keep the complete source artifact in the private repo.
2. Create a small redacted or summarized derivative.
3. Record the relationship in `docs/public_artifacts.md`.
4. Update the private manifest `public_derivatives` field.
