# Formal Transcription

Own acquisition-worker execution, raw validation and evidence-preserving
normalization. Do not import legacy modules or add semantic extraction here.
Raw files and earlier derived versions are immutable. Write only to configured
external private paths; never use public samples as runtime inputs/outputs.
Content review and structural validity are different gates. Do not invent a
review or mark real audio quality as accepted based only on passing JSON checks.
Tests use synthetic temporary data and mocked download/model functions. Do not
download audio, initialize a model or provision GPU resources without approval.
