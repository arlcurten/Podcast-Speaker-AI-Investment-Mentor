# Mentor Runtime Rules

Use reviewed private knowledge releases only. Do not import the archive or
auto-load public samples. L2 cases are evidence; L4 principles are conditional
abstractions and must retain counterevidence. Current facts require tools this
version does not have. Never make a model parse failure into an unvalidated
speaker answer. Tests are synthetic/mocked; live calls are explicit and bounded.
Full traces are private. Loopback HTTP service is not public deployment.
